# ferrante-media-premium

Speculative landing page for an AI automation agency serving premium home-service providers. Sections: hero, trust bar, problem, solution, services, industries, process, calculator, showcase, testimonials, FAQ and call to action.

The earlier Vercel deployment currently returns 404, so no live link is listed.

## Stack

React, TypeScript, Vite, Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
npm run build
```

Testimonials and figures in a pitch build like this are sample content, not real client results.
